# Portfolio Website

## About the Project

This portfolio website was created to showcase my creative work, technical skills, and growth as an IT student with an interest in creative design and web development.

The initial version was created using **Figma Make**, then independently developed and refined through code to improve its structure, functionality, and overall experience.

## Technologies Used

* **HTML** — Page structure and content
* **CSS** — Styling, layouts, animations, and visual identity
* **JavaScript** — Interactive features and dynamic behavior
* **FormSubmit.app** — Contact form integration for receiving messages by email

## Website Pages

* **Home:** A brief introduction and selected work.
* **Creative Work:** A collection of design projects and creative work.
* **Technical Projects:** A showcase of web development and other technical projects.
* **About:** Background, skills, and interests.
* **Contact:** A contact form for sending messages directly from the website.

## Key Features

* A visual identity tailored to the portfolio.
* Dedicated sections for creative work and technical projects.
* Interactive elements powered by JavaScript.
* A contact form connected to an email submission service.
* A responsive layout designed for different screen sizes.

# موفع اعمالس الشخصي - ميس فهد

## نبذة عن المشروع

موقع شخصي يهدف إلى عرض أعمالي الإبداعية ومشاريعي التقنية، وإبراز مهاراتي واهتماماتي في مجالي التصميم الإبداعي وتطوير الويب، ضمن مساحة واحدة تجمع بين الجانب البصري والجانب التقني.

أُنشئت النسخة الأولية من الموقع باستخدام **Figma Make**، ثم تولّيت تطويره وتحسينه بنفسي باستخدام الكود، بهدف تطوير بنيته ووظائفه وتحسين تجربة الاستخدام.

## التقنيات المستخدمة

* **HTML:** بناء صفحات الموقع وتنظيم المحتوى.
* **CSS:** تنسيق الصفحات وتطوير التخطيطات والحركات البصرية.
* **JavaScript:** إضافة التفاعلات والوظائف البرمجية.
* **FormSubmit.app:** ربط نموذج التواصل بخدمة استقبال الرسائل عبر البريد الإلكتروني.

## صفحات الموقع

* **الرئيسية:** نبذة مختصرة وعرض مجموعة مختارة من الأعمال.
* **الأعمال الإبداعية:** معرض لأعمال التصميم والمشاريع الإبداعية.
* **المشاريع التقنية:** عرض مشاريع تطوير الويب وغيرها من المشاريع التقنية.
* **عني:** نبذة عني ومهاراتي واهتماماتي.
* **التواصل:** نموذج يتيح للزوار إرسال الرسائل عبر الموقع.

## أهـم الخصائص

* هوية بصرية مصممة لتناسب طابع الموقع.
* أقسام مستقلة للأعمال الإبداعية والمشاريع التقنية.
* عناصر تفاعلية باستخدام JavaScript.
* نموذج تواصل مرتبط بخدمة استقبال الرسائل عبر البريد الإلكتروني.
* تصميم يراعي اختلاف أحجام الشاشات.
